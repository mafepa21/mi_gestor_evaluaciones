Notas para SwiftUI (revisión HIG)

  • Barra: «Cerrar»/«Cancelar» en cancellationAction, «Guardar» en confirmationAction con .disabled real. ⌘↩ ajusta, Esc cierra.
  • «Cancelar» con cambios sin guardar pide confirmación (interactiveDismissDisabled + diálogo).
  • Reemplazar: confirmationDialog con botón .destructive.
  • Estados con SF Symbol + texto (pencil, nosign, plus, equal), nunca solo color. Colores semánticos.
  • Tipografía con estilos (Dynamic Type); filas pasan a vertical con tamaños grandes.
  • Bloques editables: TextEditor con accessibilityLabel «Calentamiento, ahora». Antes/Ahora con etiqueta para VoiceOver.
  • Progreso: ProgressView + anuncio de VoiceOver por bloque terminado.
  • Columna máx. 820 pt, padding 24, separación 32 entre grupos y 8 dentro.
