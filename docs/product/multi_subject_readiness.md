# Multi-Subject Readiness

Mi Gestor Evaluaciones ya contiene un core docente general: alumnado, grupos, cuaderno, rubricas, asistencia, planificacion, situaciones, informes, biblioteca y backups/sync.

La conversion multi-asignatura debe reposicionar la app como herramienta docente modular. Educacion Fisica sigue siendo un vertical fuerte, pero no debe ser la identidad principal ni aparecer como obligatoria para todo el profesorado.

## Core docente

- Alumnado y grupos.
- Cuaderno evaluativo.
- Rubricas e instrumentos.
- Asistencia.
- Planificacion y situaciones de aprendizaje.
- Informes.
- Biblioteca de plantillas.
- Backups y sync.

## Verticales de dominio

- Educacion Fisica.
- Lenguas.
- Ciencias.
- Matematicas.
- Musica.
- Tecnologia.
- Personalizado.

## Criterio de diseno

Cada pantalla debe tener una tarea principal obvia, con jerarquia clara, whitespace suficiente y acciones utiles para el uso docente diario. Los modulos especificos de Educacion Fisica deben aparecer cuando el perfil docente los active o cuando aporten valor contextual claro.
