# Banco de Publicaciones para X (Docencia & IA)

Este repositorio almacena el plan de contenidos, el manifiesto fundacional y los borradores de publicaciones para X (Twitter) generados al desarrollar la app con Antigravity.

## Documentos Clave

1. **[Manifiesto Fundacional](2026-09-06-manifiesto-fundacional-app-docente.md):** Hilo fijado de presentación que explica por qué decidí crear una app nativa en Swift en lugar de usar apps comerciales, y qué papel juega la IA.
2. **[Plan Editorial](PLAN_EDITORIAL.md):** Hoja de ruta con la matriz de publicaciones secuenciadas sobre los hitos ya implementados en la app, lista para ir publicando antes de enlazar con el trabajo del día a día.

## Nomenclatura de borradores
`YYYY-MM-DD-[tema-clave].md`

Ejemplos:
- `2026-09-06-manifiesto-fundacional-app-docente.md`
- `2026-09-04-calendario-bachillerato-festivos.md`

## Estructura de cada publicación
Cada archivo incluye dos formatos listos para usar:
1. **Tweet directo** (máximo 280 caracteres): Para impacto rápido.
2. **Mini-hilo de 3 tweets**: Para desarrollar el problema real, la solución con Antigravity y una reflexión/pregunta para otros docentes.
