# Banco de Publicaciones para X (Docencia & IA)

Este repositorio almacena las propuestas y borradores de publicaciones para X (Twitter) generadas al finalizar sesiones de desarrollo de la app con Antigravity.

## Propósito
- Registrar ideas, reflexiones y aprendizajes sobre el uso de la IA aplicada a la gestión docente diaria.
- Mantener un banco de contenidos listo para revisar, copiar y compartir con la comunidad educativa.
- Evitar que los problemas reales resueltos en el aula y en la app se queden olvidados en el código.

## Nomenclatura de archivos
`YYYY-MM-DD-[tema-clave].md`

Ejemplo:
- `2026-09-04-calendario-bachillerato-ef.md`

## Estructura de cada publicación
Cada archivo incluye dos formatos listos para usar:
1. **Tweet directo** (máximo 280 caracteres): Para impacto rápido.
2. **Mini-hilo de 3 tweets**: Para desarrollar el problema real, la solución con Antigravity y una reflexión/pregunta para otros docentes.
